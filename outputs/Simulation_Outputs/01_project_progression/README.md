# 01_project_progression outputs

This folder contains outputs generated by the project-progression Monte Carlo module.

## Source script

- `simulation_codes/01_project_progression/project_progression_monte_carlo.R`

## Input workbook

- `data/Simulation_Inputs/project_progression_inputs.xlsx`

## Expected outputs

Running the script generates timestamped and latest-version outputs, including:

- baseline Monte Carlo draws
- accelerated Monte Carlo draws
- design-level quantile summaries
- descriptive summaries
- run metadata
- RDS model objects
- bundled RDS and workspace files

These outputs are generated from the current SMR design pipeline and phase-rule assumptions under Baseline and Accelerated project-progression assumptions.
