# Main figure scripts

This folder contains R scripts used to generate the main manuscript figures for the FOAK SMR deployment analysis.

The current main figure script structure is organised by figure number:

1. **Figure 1** — Historical SMR design pipeline.
2. **Figure 2** — FOAK development framework and model inputs.
3. **Figure 3** — Vendor-announced FOAK target timelines.
4. **Figure 4** — FOAK deployment outlook to 2050.
5. **Figure 5** — Projected FOAK SMR deployment by OECD membership and reactor cooling type.
6. **Figure 6** — Median regional FOAK SMR deployment trajectories and regional cooling composition.

Scripts in this folder use relative paths and are intended to reproduce the main figure outputs from the corresponding source-data workbooks in `data/Main_Figures/`.

The contents may be updated as the manuscript and supporting materials are finalised.
