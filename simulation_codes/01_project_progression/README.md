# 01_project_progression

This folder contains the project-progression Monte Carlo module used to simulate FOAK timing for the current SMR design pipeline under Baseline and Accelerated assumptions.

## Script

- `project_progression_monte_carlo.R`

## Input

- `data/Simulation_Inputs/project_progression_inputs.xlsx`

## Output

- `outputs/Simulation_Outputs/01_project_progression/`

This module estimates FOAK timing for active SMR designs using phase-duration assumptions and design-specific phase-rule overrides. It does not apply the full post-2025 pipeline-evolution module.
