# First-of-a-kind SMR deployment prospects

This repository contains data, code and selected outputs supporting the manuscript **“First-of-a-Kind deployment prospects for small modular reactors”** by J. A. Gordon, T. Kazlou, J. Jewell and A. Cherp.

The repository provides the R scripts, source-data workbooks, simulation inputs and selected model outputs used to reproduce the manuscript figures, extended data figures, supplementary figures and Monte Carlo simulation modules.

## Revision history

The repository was initially prepared for the original manuscript submission in June 2026 and was updated for the revised submission in September 2026.

In the original submission, the two model scenarios were denoted **Baseline** and **Accelerated**. For the revised submission, these were renamed **Reference** and **Proliferation**, respectively, to better reflect their analytical interpretation. The underlying scenario definitions and modelling logic are unchanged.

Files added or updated for the revised submission use the revised **Reference** and **Proliferation** terminology. Earlier repository history may therefore contain the original **Baseline** and **Accelerated** terminology.

## Repository structure

- `data/` contains source-data workbooks for the main figures, extended data figures, supplementary figures and Monte Carlo simulation inputs.
- `scripts/` contains R scripts used to reproduce manuscript figures, extended data figures and supplementary figures.
- `simulation_codes/` contains the Monte Carlo simulation modules used for project progression, pipeline evolution, post-2025 design additions and scenario-based sensitivity analyses.
- `outputs/` contains selected exported outputs, including figure files and reusable intermediate files generated by the analysis scripts.
- `CITATION.cff` provides citation information for this repository.

## Simulation modules

The simulation_codes/ folder contains 19 numbered modules. These cover the reference project-progression and pipeline-evolution analyses, post-2025 design additions, active-pipeline sensitivity analyses, post-2025 sensitivity analyses, an AMR-specific late-stage-risk sensitivity, and a regional FOAK competition sensitivity.

Each simulation-code subfolder includes a dedicated `README.md` explaining the purpose of the module, required input workbook and expected outputs. The corresponding input workbooks are stored in `data/Simulation_Inputs/`.

The production simulations use 10,000 Monte Carlo runs. For testing, the scripts can be temporarily run with a smaller value of `SIMS`, for example `SIMS <- 10L` or `SIMS <- 25L`.

## Reproducing the analyses

The scripts are written for R and use common packages including `readxl`, `dplyr`, `stringr`, `purrr`, `tibble`, `writexl`, `tidyr` and `ggplot2`, with additional packages used by individual figure scripts.

The GitHub-compatible scripts are designed to detect the repository root and read input files from the relevant `data/` subfolders. Outputs are written to the corresponding `outputs/` locations.

A typical workflow is:

1. Clone or download the repository.
2. Open the repository root as the working directory in R or RStudio.
3. Run the relevant script from `scripts/` or `simulation_codes/`.
4. Check the matching output folder for exported figures, workbooks or R objects.

## Large simulation outputs

Large Monte Carlo output files are not stored directly in this repository because of their size. Selected outputs required to document and reproduce the manuscript analyses are retained here.

The larger Monte Carlo output files and sensitivity-analysis summaries are archived separately on Figshare:

**Gordon et al., _Monte Carlo outputs and sensitivity-analysis summaries for First-of-a-Kind small modular reactor deployment prospects_.**

https://doi.org/10.6084/m9.figshare.32576658

The Figshare archive complements the simulation code, source data and figure-reproduction materials provided in this repository.
