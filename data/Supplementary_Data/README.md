# Supplementary Data source data

This folder contains source-data workbooks used to generate the supplementary figures and supplementary analyses for the FOAK SMR deployment analysis.

The current Supplementary Data source-data structure is organised by supplementary figure number. Source-data workbooks are provided for Supplementary Figs. 2--14. Supplementary Fig. 1 and Supplementary Fig. 15 are listed below for completeness, but do not have separate source-data workbooks in this folder.

   No separate source-data workbook is provided in this folder.

## Notes

These files are intended to support reproducibility of the supplementary figure scripts and exported supplementary figure outputs.

Supplementary Fig. 1 and Supplementary Fig. 15 are included in the Supplementary Information but are not accompanied by separate source-data workbooks in this folder.

Large generated simulation outputs are not stored here. They are generated locally by the relevant scripts and may be archived separately with the supplementary data materials.
