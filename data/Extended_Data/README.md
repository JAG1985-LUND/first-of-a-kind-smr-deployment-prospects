# Extended Data source data

This folder contains source data workbooks used to generate the Extended Data figures for the FOAK SMR deployment analysis.

The current Extended Data source-data structure is organised by figure number:

1. **Extended Data Fig. 1** — Global SMR design pipeline and attrition dynamics.
2. **Extended Data Fig. 2** — Conceptual design entry across the global SMR pipeline by cooling type and OECD membership.
3. **Extended Data Fig. 3** — Vendor ambition gap mapped against technology readiness.
4. **Extended Data Fig. 4** — Gaps between vendor targets and modelled FOAK deployment timelines.
5. **Extended Data Fig. 5** — Global FOAK SMR deployment across reference and sensitivity scenarios.
6. **Extended Data Fig. 6** — Global FOAK SMR deployment by reactor cooling type.
7. **Extended Data Fig. 7** — Historical SMR design pipelines and projected FOAK timelines by OECD membership.
8. **Extended Data Fig. 8** — Cross-validation of modelled FOAK deployment timing against technology and market readiness indicators.
9. **Extended Data Fig. 9** — Post-FOAK scaling window to 2050 across regional and national groupings and cooling types.
10. **Extended Data Fig. 10** — Projected SMR capacity in 2035 and 2050.

Source files are intended to support reproducibility of the Extended Data figure scripts and exported figure outputs. The contents may be updated as the manuscript and supporting materials are finalised.
